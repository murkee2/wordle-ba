# WordleBA

A Bosnian-language Wordle clone. Guess a 5-letter Bosnian word in 6 tries.

## Playing / developing

```sh
npm install
npm run dev      # local dev server
npm run build    # production build
```

## The word list pipeline

The game's word list (`src/data/words.js`) is generated by a reproducible
pipeline, not hand-picked. See `LICENSE_ATTRIBUTION.md` for what each source
is and its license.

```sh
npm run words:build
```

This runs, in order:

1. **`words:download`** (`scripts/download_sources.mjs`) — downloads every
   raw source into `data/raw/` (gitignored; ~300MB total, mostly the
   Wiktionary extract). Safe to re-run — skips files that already exist
   unless `--force` is passed. Pass `--skip-heavy` to skip the large
   Wiktionary download.
2. **`words:parse`** (`scripts/parse_sources.mjs`) — parses each raw source
   into a normalized, deduplicated candidate word list under
   `data/normalized/`, plus frequency data (wordfreq) and part-of-speech /
   category data (kaikki/Wiktionary).
3. **`words:blacklists`** (`scripts/build_blacklists.mjs`) — builds
   category-specific blacklists (Bosnian settlements, countries, rivers,
   mountains, lakes, islands, regions, given names, family names, plus
   curated vulgarity/abbreviation/brand lists) into `data/blacklists/`.
   Geography and names come from live, paginated Wikidata SPARQL queries;
   everything else is a hand-curated list. Pass `--skip-wikidata` to skip
   the network calls and use only the curated lists.
4. **`words:filter`** (`scripts/filter_words.mjs`) — merges all normalized
   sources into one candidate pool, applies the Unicode/digraph-aware
   exactly-5-letter filter (`dž`, `lj`, `nj` each count as ONE letter — see
   `scripts/lib/config.mjs` / `src/logic/graphemes.js`), removes structural
   junk (no-vowel tokens, 4+ repeated letters), and removes every blacklist
   hit. Writes `data/output/candidates_clean.json`.
5. **`words:score`** (`scripts/score_words.mjs`) — scores every clean
   candidate on cross-source presence, wordfreq frequency, and
   part-of-speech signals. See the scoring breakdown in that file's header
   comment.
6. **`words:generate`** (`scripts/generate_words.mjs`) — selects the top
   **exactly 15,000** words as `allowedWords`, and a stricter
   high-scoring subset (3,000–5,000) as `answerWords`. **Refuses to run**
   (throws instead of padding) if fewer than 15,000 clean-scored candidates
   exist. Writes `src/data/words.js`, `output/allowedWords.js`,
   `output/answerWords.js`.
7. **`words:validate`** (`scripts/validate_words.mjs`) — independently
   re-checks the generated list: exact count, no duplicates, exactly 5
   Bosnian letters per word (digraph-aware), no disallowed characters, no
   blacklisted (proper noun / geography / vulgar / abbreviation) words, and
   that `answerWords` is a subset of `allowedWords`. **Fails loudly and
   lists offending words** if any check doesn't pass — it never reports a
   false success.

### Directory layout

```
data/
  raw/           downloaded source files (gitignored)
  normalized/    per-source normalized candidate word lists (gitignored)
  blacklists/    proper-noun/geography/vulgarity/etc. blacklists (gitignored)
  output/        intermediate pipeline artifacts (candidates, scores)
scripts/
  lib/           shared utilities (grapheme tokenizer, normalization, SPARQL client)
  download_sources.mjs
  parse_sources.mjs
  build_blacklists.mjs
  filter_words.mjs
  score_words.mjs
  generate_words.mjs
  validate_words.mjs
output/
  allowedWords.js
  answerWords.js
```

## The dž / lj / nj digraphs

The Bosnian Latin alphabet has 30 letters, five of which are digraphs
written with two Unicode code points but pronounced (and alphabetized) as a
single letter: **dž, lj, nj**. This project treats them as one Wordle tile:
`src/logic/graphemes.js` tokenizes a word into its grapheme sequence rather
than splitting the raw string, and the board, keyboard, and guess evaluation
all go through that tokenizer. The virtual keyboard has dedicated dž/lj/nj
keys, and typing the two Latin letters on a physical keyboard (e.g. "d" then
"ž") merges them into the digraph automatically.
